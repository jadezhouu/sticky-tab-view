# Security Policy

## Supported Versions

| Version | Line | Supported |
|---------|------|-----------|
| 2.x | Reanimated 4 (main) | ✅ |
| 1.x | Reanimated 3 (compatibility) | Planned — supported once released |
| < 1.0 | — | ❌ |

Security fixes are backported to the current major and the previous major once the Reanimated 3 compatibility line is released.

## Reporting a Vulnerability

Please **do not** open a public issue for a security vulnerability — doing so exposes the details before a fix is available.

Report vulnerabilities privately using GitHub's **Private Vulnerability Reporting**:

1. Go to the repository **Security** tab.
2. Click **Report a vulnerability**.
3. Describe the vulnerability, the affected versions, and (if possible) a minimal reproduction.

This opens a private security advisory visible only to the maintainers until a fix is published.

## Security Response

- We will acknowledge your report within **14 business days**.
- After acknowledgement, we will reproduce, assess severity, and prepare a fix.
- We will agree on a coordinated disclosure timeline before the advisory is made public.

Please include enough detail for us to reproduce the issue: affected version, platform (iOS/Android), dependency versions (React Native / Reanimated / Worklets / Gesture Handler), and a minimal reproduction when possible.
